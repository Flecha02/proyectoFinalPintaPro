# PintaPro - Sistema de Gestión e Inventario

Este proyecto es una solución integral para la gestión de productos, inventario y autenticación de usuarios de PintaPro.

## 🛠️ Tecnologías Utilizadas

- **Backend:** Node.js, Express, MySQL.
- **Frontend:** Next.js (React), Tailwind CSS.
- **Base de Datos:** MySQL (Gestión mediante Stored Procedures).

---

### 1. Requisitos Previos
